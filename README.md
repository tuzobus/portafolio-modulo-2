# Clasificación de variedades de arroz mediante regresión logística

Implementación manual de un modelo de regresión logística para clasificar granos de arroz de las variedades Cammeo y Osmancik a partir de siete características físicas.

## Paper
El paper está disponible dentro del mismo repo como ```paper.docx```.
Eventualmente lo cambiaré a google docs para un acceso más rápido, pero intenté subir mi copia local y me salia error, así que lo tendré que hacer desde cero ahí.

## Dataset

Se utiliza el dataset **Rice (Cammeo and Osmancik)** del UCI Machine Learning Repository.

El dataset contiene:

- 3810 observaciones
- 7 características morfológicas
- 2 clases: Cammeo y Osmancik
- Sin valores faltantes

El dataset utilizado por el programa es:
```Rice_Cammeo_Osmancik.arff```
